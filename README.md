# Ikram Maldives

Website for **Ikram** — a Maldivian Islamic da'wah association founded in 2026, devoted to knowledge, worship, and community.

A single-file, dependency-free static site (`index.html`). Minimal & elegant design in an emerald-and-brass palette.

## Sections
Hero · About · Programs · Ikram Academy · Gallery · Resources · Contact

## Run locally
Just open `index.html` in any browser, or serve it:

```bash
npx serve .
```

## Deploy
Hosted on [Vercel](https://vercel.com). Any push to `main` redeploys automatically once the repo is linked.
